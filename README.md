# match-3-lua-test
Тестовое задание матч 3 консольная игра на языке Lua
Игра запускается через Lua интерпретатор.
Команды:
  m x y d  - двинуть кристалл: x и y от 0 до 9,
  d - направление: l (влево), r (вправо), u (вверх), d (вниз)
  q - выход
  Пример: m 3 0 r

  В разработке использовано ООП. Разделены View и Model. Так же с помощью полиморфизма и наследования сделана заготовка для специальных кристалов.
